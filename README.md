# Veteran Wife Bakes – Collection Time Picker

Website: https://veteranwifebakes.co.uk/

A WooCommerce checkout plugin for a bakery.

## What it does
- Adds a collection date and time picker to the checkout.
- Makes cupcake orders pickup-only and hides the delivery option.
- Checks that the chosen time slot is valid before the order is placed.
- Saves the collection details with the order so the shop can see them.
